# Abacate Launcher

> **Nota:** Este projeto é um fork do [Olauncher](https://github.com/tanujnotes/Olauncher), desenvolvido originalmente por [@tanujnotes](https://x.com/tanujnotes). A partir deste fork, o aplicativo passa a se chamar **Abacate Launcher**.

---

O **Abacate Launcher** é um launcher minimalista, de código aberto e livre de anúncios para Android (AF - *Ad-Free*).

### Sobre o projeto original (Olauncher)

Para manter a simplicidade do launcher, alguns recursos específicos estão disponíveis, mas ocultos.
Confira a página **[About](https://tanujnotes.substack.com/p/olauncher-minimal-af-launcher?utm_source=github)** nas configurações para ver a lista de recursos e **FAQs**.
